# SAL: A Symbolic Analysis Laboratory

SAL is a framework for combining different tools for abstraction, program analysis, theorem proving, and model checking toward the calculation of properties (symbolic analysis) of transition systems.

A key part of the SAL framework is a language for describing transition systems. This language serves as a specification language and as the _target_ for translators that extract the transition system description for popular programming languages such as Esterel, Java, and Statecharts.

The language serves as a common _source_ for driving different analysis tools through translators from the SAL language to the input format for the tools, and from the output of these tools back to the SAL language.

The SAL language was originally designed in collaboration with David Dill of Stanford University and Thomas Henzinger of the University of California, Berkeley.


For more on SAL, see the SAL website @ http://sal.csl.sri.com.
